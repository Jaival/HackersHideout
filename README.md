# Hacker's Hideout

A dark VS Code theme with a near-black background, lime-green text and neon accents.

## Install

Search for "Hacker's Hideout" in the Extensions view (`Ctrl+Shift+X`), install it, then pick it with `Ctrl+K Ctrl+T`.

Or from the command line:

```sh
code --install-extension JaivalSaija.hacker-hideout
```

## What's themed

The whole workbench, plus the terminal's 16 ANSI colors, Git and diff decorations, the debugger, notebooks, inlay hints, sticky scroll, bracket pair colors and the chat panels. Semantic highlighting is on, so languages with a language server (TypeScript, Python, Rust, Go, C# and others) color parameters, properties, types and deprecated symbols on their own.

## Palette

| Color | Hex | Used for |
|---|---|---|
| Background | `#15171E` | Editor, sidebar, panels |
| Surface | `#313831` | Widgets, inputs, inactive tabs |
| Text | `#BEDE90` | Default text |
| Bright text | `#DAFFA3` | Variables, emphasis |
| Comment | `#7D9161` | Comments (italic) |
| Cyan | `#00FFFF` | Functions, escape characters |
| Sky | `#78E3FD` | Keywords, cursor, focus |
| Lavender | `#B3B3FF` | Types, classes, status bar |
| Pink | `#E5446D` | `const`, `let`, modifiers, tags |
| Salmon | `#F4B9B2` | Strings |
| Yellow | `#FFD800` | Numbers, constants, warnings, modified files |
| Green | `#7CFC8A` | Object keys and properties, added lines and files |
| Red | `#FF5A34` | Errors, deleted lines |

## Feedback

Found something hard to read or a color that clashes? Open an issue at [github.com/Jaival/HackersHideout](https://github.com/Jaival/HackersHideout/issues) with a screenshot and the language you were editing.
